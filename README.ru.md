# Google Photos Quota Reclaim

Освобождает место в Google Photos. Находит фото, занимающие квоту, скачивает их, удаляет из облака и повторно загружает через **Pixel 1** с его безлимитным бэкапом в оригинальном качестве — после чего фото снова в облаке, но квоту не занимают.

## Возможности

- **Сохранение альбомов** — запоминает членство в альбомах до удаления и восстанавливает после повторной загрузки
- **Сохранение общих альбомов** — запоминает членство в общих альбомах до удаления и восстанавливает после повторной загрузки
- **Сохранение архива** — определяет архивированные фото и автоматически архивирует их снова после загрузки
- **Автоматический перенос на Pixel** — отправляет файлы прямо на устройство по USB через ADB, без ручного копирования
- **Прерываемый процесс** — каждый шаг идемпотентен; можно остановиться и продолжить в любой момент без потери прогресса
- **Параллельная обработка** — настраиваемое количество потоков для ускорения удаления и загрузки
- **Сохранение метаданных** — опциональная интеграция с [GooglePhotosTakeoutHelper Neo](https://github.com/Xentraxx/GooglePhotosTakeoutHelper_Neo) для восстановления оригинальных дат и GPS из сайдкаров Takeout перед повторной загрузкой
- **Понятный интерфейс** — пошаговый GUI ведёт через весь процесс с обновлением статуса в реальном времени
- **Интерфейс на английском, русском, традиционном китайском, упрощённом китайском и японском** — переключается одним кликом

## Требования

- **Google Chrome** — должен быть установлен (приложение запускает и управляет им автоматически)
- **Node.js 18+** — скачать с [nodejs.org](https://nodejs.org/) (рекомендуется LTS-версия)
- **Pixel 1** с включённой отладкой по USB и режимом бэкапа «Оригинальное качество» в Google Photos
- Windows 10/11 (macOS и Linux поддерживаются, но требуют ручной настройки ADB — см. ниже)

## Быстрый старт

1. **Скачай** архив последнего релиза и распакуй в любую папку <!-- добавить ссылку на релиз -->
2. **Запусти приложение** — запусти `Google Photos Quota Reclaim.bat`; окно программы откроется автоматически
3. **Открой Chrome** — нажми **Launch Chrome** в верхней панели, затем войди в Google Photos в открывшемся окне браузера
4. **Подключи Pixel 1** по USB — индикатор ADB в верхней панели станет зелёным при обнаружении устройства
5. **Нажми Load** в боковой панели, выбери альбомы и следуй инструкциям программы

## Настройка ADB

### Windows

ADB включён в архив релиза — дополнительных действий не требуется.

### macOS / Linux

Скачай [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) с официального сайта Android, распакуй архив и скопируй бинарник `adb` в папку `adb/` рядом с приложением, заменив файл-заглушку.

## Как это работает

1. **Сканирование** — выбери альбомы в боковой панели (или включи *Scan all library*) для поиска всех фото, занимающих квоту; приложение также определяет архивированные фото и сохраняет членство в альбомах
2. **Привязка файлов** — приложение скачивает оригиналы в папку `downloads/`; нажми Match, чтобы привязать файлы к манифесту
3. **Удаление и загрузка на Pixel** — удаляет фото из Google Photos и отправляет их на Pixel по USB *(необратимый шаг)*
4. **Подожди 1–4 часа** — Google Photos на Pixel делает бэкап файлов в облако в оригинальном качестве, бесплатно
5. **Проверка** — подтверждает, что квота освобождена для каждого фото; кнопка View показывает, какие ещё ожидают подтверждения
6. **Восстановление альбомов и архива** — возвращает фото в исходные альбомы и архивирует те, что были архивированы раньше
7. **Очистка Pixel** — удаляет отправленные файлы с устройства

> **Совет по метаданным:** чтобы сохранить оригинальные даты и GPS-координаты, обработай скачанные файлы через [GooglePhotosTakeoutHelper Neo](https://github.com/Xentraxx/GooglePhotosTakeoutHelper_Neo) перед запуском Match.
